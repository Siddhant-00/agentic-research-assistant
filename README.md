# Agentic Research Assistant

I built this project to explore how modern AI systems can go beyond a traditional chatbot and behave more like an intelligent research assistant.

Instead of directly sending a user query to an LLM, the system rewrites the query, decides where information should come from, retrieves relevant context, reranks the retrieved documents, verifies the generated answer, and finally returns a response with citations.

The goal was to understand and implement the core building blocks that power production-grade AI assistants.

---

## What the system does

When a user asks a question, the workflow looks like this:

User Query

↓

Query Rewriter

↓

Source Router

↓

Knowledge Retrieval

↓

Cross-Encoder Reranking

↓

Answer Generation

↓

Answer Verification

↓

Source Attribution

↓

Final Response

## Supported Knowledge Sources

The assistant can retrieve information from multiple sources depending on the user's question.

### Internal Knowledge Base

A FAISS vector database built from AI-related articles including:

* AI Agents
* Prompt Engineering
* Adversarial Attacks on LLMs

### Wikipedia

Used for general knowledge questions.

Examples:

* Who is Geoffrey Hinton?
* What is reinforcement learning?

### Arxiv

Used for research-oriented questions.

Examples:

* Recent transformer research
* Diffusion models
* Retrieval-Augmented Generation papers

---

## Interesting Parts of the Project

### Query Rewriting

Follow-up questions are often ambiguous.

Example:

User:
What are memory systems in AI agents?

User:
Tell me more about long-term memory.

The system rewrites the second question into a self-contained query before retrieval.

---

### Intelligent Routing

Not every question should hit the same data source.

A routing agent decides whether a question should be answered using:

* Internal vector database
* Wikipedia
* Arxiv

This reduces irrelevant retrieval and improves response quality.

---

### Cross-Encoder Reranking

Retrieval systems often return partially relevant documents.

After retrieval, a Cross-Encoder model reranks the documents and selects the most relevant context before answer generation.

Model used:

cross-encoder/ms-marco-MiniLM-L-6-v2

---

### Answer Verification

Instead of trusting the first answer generated by the LLM, a separate verification step checks the response against the retrieved context and removes unsupported claims.

This helps reduce hallucinations and improves factual consistency.

---

### Source Attribution

Responses include the sources used to generate the answer so users can understand where the information came from.

## Running the Project

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/agentic-research-assistant.git
cd agentic-research-assistant
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```env
GROQ_API_KEY=your_key_here
```

Build the vector index:

```bash
python database/ingest.py
```

Start the application:

```bash
streamlit run app.py
```
